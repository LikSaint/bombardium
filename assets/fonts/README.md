# Fonts

`DejaVuSans.ttf` — DejaVu Sans, used only as a *fallback* behind Godot's built-in font
(see `ControlHints._ready`). It carries the button glyphs (✕ □ ○ ◄ ►) that the built-in
font lacks or draws tiny, so they look the same on every platform instead of depending on
whatever fonts the system happens to have.

DejaVu fonts are free to use and redistribute under the Bitstream Vera / DejaVu licence:
https://dejavu-fonts.github.io/License.html
